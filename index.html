Sheet layout

Measure your label sheet with a ruler and enter it once. The app then fills every label in a row before starting the next, so nothing is wasted. Use Skip to start part-way down a sheet you have already used.

Send to BarTender

Exports the ticked labels above as a CSV that BarTender reads through File → Database Connection Setup → Text File. One row per label design; the COPIES column holds how many to print. Codes come from here — never type a new one into BarTender.

Where the data is kept

Category rules

Each category owns a code prefix, so a code tells you what the part is before you read the name. Terminals become TRM-0001, couplers CPL-0001. Changing a prefix only affects codes created from now on — existing codes never move.
